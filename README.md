# TorchLessCUDA

![Build Status](https://github.com/YOUR_USERNAME/TorchLess/actions/workflows/cmake-build.yml/badge.svg)

A lightweight CUDA accelerated deep learning framework built from scratch using modern C++ and CUDA.

TorchLessCUDA aims to explore the fundamentals behind GPU accelerated computing and neural network frameworks by implementing tensor operations, CUDA kernels, and deep learning primitives without relying on existing frameworks like PyTorch or TensorFlow.

---

## 🚀 Overview

Modern deep learning frameworks hide most of the complexity behind high-level APIs. TorchLessCUDA focuses on understanding and implementing the lower-level components that make these frameworks possible:

- GPU memory management
- CUDA kernel execution
- Tensor operations
- Parallel computation
- C++/CUDA architecture design

The project is built with a clean separation between C++ interfaces and CUDA implementations, following a modular design similar to production-grade GPU libraries.

## ✨ Current Features

### CUDA Integration

- CMake-based CUDA build system
- Modern C++20 support
- CUDA kernel execution
- GPU memory allocation and data transfer
- CPU/CUDA separation through clean interfaces
